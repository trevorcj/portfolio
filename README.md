# Chimamanda Justus

Personal portfolio and website for Chimamanda Justus, a frontend developer based in Lagos, Nigeria.

Built to showcase my work, experience, writing, and the things I'm building and learning along the way.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP
- Vercel
